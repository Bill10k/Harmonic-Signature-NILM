# Contribution Guidelines

## Rules

- One MATLAB function per file.
- Use meaningful variable names.
- Comment every function.
- Do not modify another member's module without informing them.
- Keep functions modular.

---

## Commit Messages

Good examples

```
Add voltage sag implementation

Implement FFT analysis

Add feature extraction module

Fix FIR filter bug
```

Avoid

```
update

changes

fixed
```
